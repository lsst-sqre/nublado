### Bug fixes

- On abnormal Lab startup, fall back to `/tmp` when `$SCRATCH_DIR` is set but the abnormal-startup report cannot be written there, which happens when scratch is really on the same volume as the home directory. Previously the temporary home directory was reset to `$SCRATCH_DIR` afterwards regardless of where the report was actually written, so the Lab could start in a directory with no explanation of what went wrong. If neither location is writeable, startup now fails with `ENOWRITEABLESERVERROOT` rather than starting a Lab that cannot report the problem.
